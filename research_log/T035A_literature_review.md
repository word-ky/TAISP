# T035-A / R053 — literature-grounded reset

Status: NEEDS_REVIEW. Search date: 2026-09-14. Authority: research continuation R053 at `44030b0`. Literature/design only: zero model calls, zero GPU jobs, zero implementation changes. Findings below distinguish published mechanisms from our inference; they are not TAISP experimental results.

## Positioning result

The broad story “freeze the vision model and adapt how the image looks” is already substantially covered. **AdaptiveISP** is the most direct task/ISP threat; **VPTTA** is the closest per-image, frozen-model, input-adaptation threat. A learned deployment loss is also established prior art, including **NC-TTT**, the older conjugate-loss study, and **Learn-to-Steer**. The remaining defensible question is narrower: can a source-supervised scalar objective provide a *new, sample-specific, detection-useful image gradient*, transferable to unseen images, while all detector weights and loss-network weights stay frozen at deployment? This is an unverified mechanism/evidence gap, not a novelty claim established by absence in this search.

R052's high unsigned span ceiling does not answer that question. T034's excess-over-hard matched-null failure closes its exact H/C/N mixing proposal. It does not establish impossibility of every learned image loss, every spatial ISP, or every source-trained representation.

“No source co-training” does not mean no source information: stored statistics, source-trained heads, domain names and multiple pretrained models are distinct resources. “Geometry” below distinguishes actual box/depth constraints from classification sensitivity to shape. No paper's reported gains are treated as comparable to TAISP's frozen COCO diagnostic.

## Older novelty boundaries (not counted as recent additions)

- **O01 — Test Time Adaptation via Conjugate Pseudo-labels**, Sachin Goyal, Mingjie Sun, Aditi Raghunathan, J. Zico Kolter; [NeurIPS2022 proceedings](https://proceedings.neurips.cc/paper_files/paper/2022/hash/28e9eff897f98372409b40ae1ed3ea4c-Abstract-Conference.html). It explicitly meta-learns a TTA loss and relates the result to the supervised training loss's convex conjugate. Generic “learn the unlabeled loss from source task supervision” is therefore not a new invention. Its classification/conjugacy setting does not prove a loss for a nonconvex frozen detector composed with ISP.
- **O02 — MT3: Meta Test-Time Training for Self-Supervised Test-Time Adaption**, Alexander Bartler, Andre Bühler, Felix Wiewel, Mario Döbler, Bin Yang; [author arXiv2103.16201, v2 January2022](https://arxiv.org/abs/2103.16201). Historical preprint record used here; no conference acceptance asserted. Meta-trains for a self-supervised single-image inner update of model parameters. It is a relevant antecedent, but learning update-ready initial model weights differs from learning only a scalar loss while detector weights remain fixed.

## C. Seven design principles and evidence strength

1. **Source co-design is an important route, not a universal necessity** — multiple papers: P01/P02/P13 explicitly tie an auxiliary task to source training, P12 aligns support/query training with deployment. Counterexamples P03/P10/P11 use pretrained models and non-co-trained adaptation signals. Inference: TAISP should test co-design because its existing proxies failed, not claim every successful TTA method requires it.
2. **Confidence is not correctness, and selection cannot repair an uninformative scalar automatically** — multiple: P06 calibrates instance confidence; P11 uses an intervention-derived reliability score; P03/P04 avoid relying only on pseudo-label CE by using feature statistics. These are different mechanisms. None guarantees reliable pseudo boxes for TAISP's detector.
3. **Semantic and geometric errors need distinguishable evidence** — one particularly close paper: P05 explicitly couples class uncertainty and normal-field geometry. P02 supplies supporting evidence in segmentation, with different temporal/depth assumptions. Our speculation: a 2D input-loss analogue needs localization-sensitive source supervision; adding an entropy gate is insufficient.
4. **Select the adaptation location/state and budget from a stated observable** — multiple: P03 updates adapters selectively in time; P04/P07 act on feature discrepancy; P09 selects ISP operations/cost; P10 uses per-image prompts. Inference: channel discrepancy, predictive correctness, and pixel corruption severity are different quantities and should not be renamed interchangeably.
5. **Moving adaptation to the input changes the feasible update set, not automatically the objective** — multiple carrier precedents P09/P10/P14. Our mathematical inference: for fixed detector D and image transform Iϕ, an image cotangent v yields gϕ=Jϕᵀv. Extra spatial columns enlarge reachable directions but cannot create correct task information in v. No invertible ISP can restore information already clipped away. TAISP currently edits decoded RGB, so RAW sensor claims require separate evidence.
6. **A learned loss and a state predictor are different computations, but can be degenerate equivalents** — O01 and P15 directly support learned objectives; P08 supports inner/outer gradient coupling; P12 supports source/deployment matching but uses generated prompts. Our inference: a scalar linear in explicit ϕ merely encodes a predicted update; claiming novelty from renaming a vector head Lψ would be invalid. The new scalar must read the current transformed observation and improve held-out finite-step task behavior, including away from identity.
7. **Spatially varying adaptation has capacity evidence, not yet a qualifying TAISP supervision signal** — P14 supplies one close spatial enhancement precedent; P05 supplies a different 3D signal. T015 demonstrates local task-relevant capacity but its pseudo utility fails. Our speculation: localization-supervised source loss might use that capacity. This review does **not** establish that it will; no second spatial method card is advanced.
