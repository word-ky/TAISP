# T035-A — one method card, NOT IMPLEMENTED

Status: NEEDS_REVIEW. This is a proposed falsification protocol for the research lead to accept or replace in a new task. No cohort has been selected, model trained, image updated, or GPU job started. Numerical choices below are proposed precommitments, not measured results or an already authorized experiment.

## Card 1: source-trained current-observation task surrogate

**Claim to test:** a source-supervised scalar of the currently transformed image can induce a sample-specific, detection-useful ISP descent step on unseen images while both detector and scalar network remain frozen at deployment. Generic learned losses, frozen detectors and adaptive ISP are not claimed as new.

**Closest recent work and exact risks:** P01 NC-TTT already source-trains a deployment auxiliary objective, but its source-density objective and encoder updates differ from supervised utility of an input step. P02 depth-aware TTT co-designs source supervision and deployment consistency; it has depth/video evidence absent here. P09 AdaptiveISP already trains task-driven ISP decisions using a fixed detector, making the broad TAISP story non-novel. P15 Learn-to-Steer already learns a scalar from internal model features and optimizes an inference state through a frozen generator. A change from latent to ISP state alone is insufficient novelty. Full metadata/primary links: [audit](T035A_literature_review.md). Older O01 meta-learned conjugate loss and O02 MT3 prevent claiming invention of meta-TTT; source one-step task supervision is an antecedent, not the contribution.

**Proposed computation.** Let D be the unchanged source Faster R-CNN, Iϕ the existing eight-dimensional global ISP and F a differentiable fixed backbone/FPN feature tensor from D. For each fixed pyramid level, a shared two-layer, width-32 pointwise MLP with smooth activation reads the current feature and the detached corresponding raw feature; average its scalar outputs across positions/levels to define Lψ. Use the existing equal-channel FPN levels without a new feature projection. Do not feed explicit ϕ, H/C/N gradients, task gradients, object labels, corruption tags, or a trained tangent-correction vector into this head. Raw and transformed feature coordinates share the same image geometry.

At deployment, reset ϕ=0, compute g=∇ϕ Lψ(F(Iϕ(x)), stopgrad(F(x))), then take exactly one step ϕ'=project_bounds(ϕ−0.01 g/max(||g||₂,10⁻⁸)). A zero gradient leaves identity. This normalization and step are design choices in existing normalized ISP coordinates; retain existing operator bounds. No optimizer state or memory crosses images. D and ψ never update at deployment. A learned scalar is minimized only to produce this image step; an increasing scalar value is not itself detection evidence.

**Source supervision and train/deployment separation.** Source images and their detection labels may train ψ through the actual one-step supervised detector loss ℓdet(D(Iϕ'(x)),y). Differentiating this outer loss through the inner step requires mixed/second derivatives; detector parameters remain frozen but its input graph is differentiable. Train only ψ. Include source clean and fixed corrupted observations and identity plus a small predeclared nonidentity state distribution (uniform within ±0.01 in normalized coordinates, clipped to existing bounds). This teaches a field on current observations, not only an identity gradient. Use the unchanged native supervised detection-loss definition; no extra CLIP/hard/native mixture coefficient training. Source train labels are never supplied to Lψ. Fixed raw anchors are per-current-image observations, not clean target references.

Forbidden at deployment: test labels/boxes, source annotations, clean counterpart, corruption family/severity identifier, oracle depth or task gradient, source nearest-neighbor label memory, target-domain adaptation labels, holdout-informed step selection. Test labels are accessible only in a separate post-lock offline evaluator. The source-trained ψ checkpoint is frozen before holdout candidate generation and any holdout label evaluation.

**Why this might escape T034, and why it may not.** Its image cotangent is learned from source task utility through current feature derivatives and is not constrained to span the old three scalar gradients. This is a possibility, not a guarantee of useful excess. It may still learn confidence/density shortcuts or a near-constant direction. Unlike the failed T013-I fixed-summary affine ϕ predictor, the scalar is re-evaluated on the transformed observation and differentiated through the image. However, at identity a gradient field can behave like a vector predictor; an identity-only result is not enough to claim a distinct mechanism. Check the same locked scalar at the predeclared nonidentity states and report whether one-step utility persists. No additional architecture is proposed as a fallback.

**Smallest proposed fresh falsification.** Reserve 420 new source-domain image IDs: 240 train, 60 calibration, 120 untouched holdout, seed 20261006. Exclude all cumulative 3,911 prior/reserved IDs recorded by T034, plus existing validation/evaluation sets. This is a proposal, not a new data split artifact. For each image use one clean and one corrupted observation; distribute the existing fixed corruption families evenly, retaining existing severity definitions. Holdout has 240 episodes in four fixed blocks of 30 paired images. Train ψ for ten fixed passes with Adam, learning rate 10⁻³, batch one paired image; fixed seed, no holdout stopping. Calibration is for recording loss scale/numerical feasibility, not selecting a better architecture, step, checkpoint or gate. If these choices are infeasible, report that before revealing holdout labels rather than silently changing them.

Freeze ψ, directions, transform outputs and all protocol choices before holdout annotation evaluation. Compare the one-step task-loss change against no-adapt, unchanged hard-only normalized step at the same length, and 256 paired image-permutations of the learned directions, preserving clean/corrupt family and step-norm distribution. Permute complete image pairs within family so the unit remains image, not independent clean/corrupt rows. Also train one fixed negative-control ψ with source label assignments permuted between source image pairs (same boxes/classes transferred in normalized image coordinates) before holdout; it controls task/image correspondence, not a hyperparameter alternative. Report all controls, including failure. No AP, target detector, K-step or spatial extension belongs to this first falsification.

**Proposed advance/stop conjunction.** Define relative task gain r=(ℓbefore−ℓafter)/max(ℓbefore,10⁻⁸). Require (i) positive signed source-task gradient alignment in at least 156/240 episodes and 84/120 corrupted episodes; (ii) median r ≥1% overall and corrupted, with clean median r ≥0; (iii) mean paired gain advantage over unchanged hard and the shuffled-supervision head with a strictly positive 95% image-paired bootstrap lower bound (2,000 resamples, fixed seed); (iv) median gain above the 95th percentile of the paired-permutation control medians overall and corrupted, with at least three of four block mean gains positive. Report nonidentity utility as a required mechanism diagnostic; failure there blocks a claim of learned update dynamics even if identity passes. Any failed main conjunction closes this exact card without same-cohort tuning. Passing permits research review of a separate external/AP study, not automatic deployment or a claim of cross-detector benefit. Thresholds are proposed practical requirements; literature does not validate these particular numerical cutoffs.

**Complexity and main uncertainty.** One small scalar head, one inner step, one outer source objective; implementation is moderate because second-order differentiation through the existing detector/input path must work. Expected budget is several thousand source episode updates (about 4,800 condition evaluations across ten passes per head, doubled for the shuffled-supervision control) plus fixed controls and 240 holdout episodes; a rough planning allowance is 4–12 A6000 GPU-hours, not a measurement or quota request. Frozen weights save optimizer state, not input-backward/second-order compute. If an observed unsupported derivative blocks this exact computation, stop and report it for design review; do not silently substitute a direct-vector predictor. Source task-loss improvement can still fail cross-detector AP, and the closest-work novelty risk remains high even if this small study passes.

## No second card

P14 establishes a spatial carrier and T015 establishes extra local capacity, but neither supplies new label-free detection supervision. P05's 3D geometry signal is unavailable in the current 2D image setting. Therefore a spatial/reliability second hypothesis is not justified by this audit. Revisit only if a concrete measurable supervision source is established; no third fallback is proposed.
