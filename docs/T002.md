# T002: real-signal feasibility protocol

This study asks whether a frozen CLIP restoration gradient in ISP space aligns
with a frozen detector's task gradient. It does not train either model or make
a full-COCO benchmark claim. Protocol choices precede the results in
`research_log/T002_plan.md` and `configs/t002.yaml`.

## Models and reproducibility

- OpenAI CLIP ViT-B/32 via Transformers 4.44.2, Hugging Face revision
  `3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268`.
- torchvision 0.19.0 Faster R-CNN ResNet50 FPN, `COCO_V1`, native 800/1333
  transform, normal eval predictions, default score threshold and NMS.
- Both float32, all parameters frozen, no autocast, no learned prompt/predictor.
- Runtime packages and full model-file SHA256 hashes are saved per run.
- Tensor CLIP preprocessing: shortest side 224, bicubic antialias, center crop,
  published RGB normalization. Decoding PIL images occurs before the gradient
  path. Unlike PIL preprocessing, tensor bicubic values are not quantized or
  reclipped; this explicit variant preserves differentiation.
- CUDA antialiased bicubic backward in torch 2.4 is not bitwise deterministic.
  Forward preprocessing and initial episodic state are deterministic; update
  reproducibility is numerical (tested at atol 1e-8, rtol 1e-5). The observed
  repeat noise was about 1e-10, independently of episode state.

## Semantic objective and deployment boundary

For unit CLIP image embedding e(x), positive text-bank mean p and negative-bank
mean n (each formed from unit prompt embeddings), use:

`d = normalize(normalize(p) - normalize(n))`

`L_sem(x,y) = - <e(y) - stopgrad(e(x)), d>`.

Positive bank covers natural/clear/well-lit photographs; six negative prompts
cover darkness/underexposure, low contrast/haze and color cast. Exact strings
are in `taisp/losses/clip_semantic.py` and run metadata. The same generic
direction is used for every sample, independent of corruption family/severity.
No annotations or corruption labels enter `adapt()`. At identity, displacement
is zero but the derivative of this projection is finite.

Every image starts from zero raw phi. CLIP-only raw SGD uses lr=0.1 for three
steps; the intermediate first step and final third step are evaluated.
Consistency and state regularization weights are zero. There is no oracle
gradient, label, corruption selection, detector loss or learned state in TTA.

## Oracle analysis boundary

`taisp/analysis/oracle.py` calls the detector's native four-term RPN/ROI loss
with COCO annotations, exclusively in offline analysis. To request those losses,
the top model/RPN/ROI-head loss-branch flags are temporarily set to training.
All backbone/transform children remain eval, parameters remain frozen, and flags
are restored to eval. Tests compare all weights/buffers before and after.

Proposal/ROI sampling uses a forked RNG seeded by study seed + image ID for
each evaluation; the same seed is used before and after updates. Native proposal
matching/sampling still makes this loss piecewise smooth. This diagnostic loss
is not the AP metric and changing candidate assignments can affect finite-step
loss comparisons. Normal AP predictions always use the model's inference path.

At the same zero phi, record g_sem and g_det. A positive cosine means their
negative-gradient directions agree locally. Evaluate whether the first semantic
SGD step reduces the annotated loss. The oracle diagnostic is one raw step
`-0.01*g_det`. It is an analysis-only comparator requested as an oracle upper
bound, not a guaranteed mathematical upper bound on AP or finite-step loss.

## Data, comparisons and outputs

From sorted COCO-val2017 IDs, Python random seed 20260912 selects 200 without
replacement. Save exact IDs, original annotation hash and each JPEG hash.
Do not select samples by measured quality or category. Crowd/invalid boxes are
excluded only from the training-style oracle targets; the original official
annotations, including crowd handling, are used unchanged by COCOeval.

Three families, two severities each: gamma exponent 1.5/2; contrast factor
0.6/0.3 about 0.5; RGB gains [1.2,1,0.8]/[1.4,1,0.6] with output clipping.
These are controlled shifts, not a standard corruption benchmark. Image geometry
is unchanged. Clean, corrupted, semantic1, semantic3 and oracle1 comparisons
share the same images/annotations. Report bbox AP on this fixed subset using
pycocotools 2.0.10; do not average separate-image APs to approximate subset AP.

Run output contains environment.json, subset.json, samples.jsonl (all 1200
image/corruption records with gradients and step traces), predictions/*.json,
metrics.json, summary.json, scatter.csv and completion.json. Scatter delta is
`L_det(after semantic step)-L_det(before)`: negative values indicate improvement.
Summary includes physical-parameter changes, cosine distribution, loss-decrease
fractions, semantic loss, output saturation and resource use. Adaptation latency
covers the three-step call with CUDA synchronization and diagnostics, excluding
oracle/evaluation/data loading. Peak allocated memory includes loaded models.

## R003 supplementary analysis and parity

`scripts/analyze_t002_linear.py` computes `-semantic_lr * dot(g_det,g_sem)`
from saved initial gradients and compares it to observed one-step detector-loss
changes. It reports strict sign agreement (zeros counted explicitly), Spearman
and Pearson correlations for both linear prediction and cosine, p05/p25/median/
p75/p95 distributions and 95% percentile bootstrap intervals. The 2,000 draws
use seed 20260912 and resample image IDs, retaining all six conditions together
for overall intervals. Correlation intervals are exploratory with no multiplicity
adjustment. Postprocessing used NumPy 1.26.4, SciPy 1.13.1 and Matplotlib 3.9.2
locally. A known linear relation with repeated image clusters verifies signs,
correlations and cluster counts.

The forward-only parity diagnostic compares 7 shapes × natural/noise images,
including 612x612 and odd rectangles, against Transformers 4.44.2's reference
CLIPImageProcessor with explicit published settings. It separates geometric
crop placement from PIL interpolation/quantization. Predeclared tolerances are
geometry max difference <=1e-7 and normalized full-output RMSE <=0.02.
R003 found a one-pixel mismatch from round versus the reference floor offset;
the completed pre-correction run is marked preliminary. After using floor crop
placement, all 14 cases have zero geometric difference; maximum normalized RMSE
is 0.005910955. The final 200-image study restarts unchanged after this correction.
